1Тип выписки

Сделки без даты закрытия (или с «In corso») попадают в открытые, с датой закрытия — в закрытые.

2Сделки пример

Вставьте таблицу сделок прямо из CRM, вместе с заголовками (ID, Pair, Type, Amount…) — каждая ячейка может быть на своей строке, пустые ячейки не мешают. Статус Open — открытая сделка, Closed — закрытая (с End time).
Ещё поддерживается формат «одна сделка — одна строка»: ID Инструмент Buy/Sell Капитал Плечо Открытие Закрытие P/L.

Импорт: файл с колонками ID, Pair/Instrument, Type, Amount/Capital, Leverage, Start time/Open, End time/Close, PNL. Поддерживаются CSV с запятой или точкой с запятой и TSV. Существующие сделки будут заменены.
