# Estratto Operazioni

Генератор PDF-выписок по открытым и закрытым сделкам. Это статический сайт: сервер и база данных не нужны.
Вся обработка (разбор сделок, сборка PDF, QR-код, логотип) идёт в браузере пользователя, данные клиентов никуда не отправляются.

## Что внутри

```
index.html        — сам сайт
fonts/            — шрифт Inter для PDF (обязательно рядом с index.html)
vendor/           — библиотеки: jsPDF (PDF), qrcode-generator (QR), pdf.js (предпросмотр)
vercel.json       — кэширование и запрет индексации поисковиками
```

## Деплой на Vercel

### Вариант 1 — через GitHub (удобно обновлять)
1. Создайте новый репозиторий на GitHub и загрузите в него содержимое этой папки (все файлы и папки `fonts`, `vendor`).
2. На vercel.com: **Add New → Project → Import** этот репозиторий.
3. Framework Preset: **Other**. Build Command — пусто. Output Directory — пусто (корень).
4. **Deploy**. Через минуту сайт будет доступен по адресу вида `имя-проекта.vercel.app`.

### Вариант 2 — из терминала
```bash
cd vercel-estratto
npx vercel          # первый раз: войти и ответить на вопросы (настройки по умолчанию)
npx vercel --prod   # выложить в продакшн
```

### Свой домен
Vercel → проект → **Settings → Domains** → добавить, например, `statements.вашсайт.com` и прописать DNS-запись, которую покажет Vercel.

## Важно

- Настройки (компания, адрес, сайт для QR, логотип) хранятся в браузере — у каждого компьютера/браузера свои.
- Сайт закрыт от поисковиков (`noindex`), но открыт любому, у кого есть ссылка. Сам по себе он ничего не хранит,
  но если нужна защита паролем — включите **Vercel → Settings → Deployment Protection** (на платных тарифах)
  или держите ссылку только у сотрудников.
- Формат вставки сделок: таблица прямо из CRM (каждая ячейка на своей строке) или «одна сделка — одна строка»:
  `ID  Инструмент  Buy/Sell  Капитал  Плечо  Открытие  Закрытие  P/L`.

## Выписка по торговому счёту

Раздел **Account Statements / Торговый счёт** работает независимо от выписки по сделкам.
Сейчас доступен ручной ввод; автозаполнение помечено как «В разработке» и отключено.

- Укажите клиента, Account ID, дату выписки и валюту оценки. Публичный ID в выписке по счёту не используется.
- Добавьте денежные остатки и криптоактивы: название, символ, кошелёк, количество и цену в валюте оценки.
- Стоимость каждой позиции — количество × цена, с округлением до четырёх знаков; общий баланс — сумма стоимостей позиций. Для расчётов используется точная десятичная арифметика.
- Операции вводятся отдельно: дата, тип, сумма со знаком, валюта, описание и необязательный ID. Они не прибавляются повторно к остаткам; суммы разных валют не складываются.
- В PDF вместо Stocks Portfolio выводится **Movimenti del conto**. Если операции не введены, документ сообщает, что данные о них не предоставлены.
- Реквизиты компании, QR-сайт и логотип общие для обоих видов выписок. Полный редактор SVG-логотипа доступен прямо в каждом разделе: загрузка, выбор элементов, перекрашивание, сброс и удаление. Данные счёта сохраняются отдельно в браузере.
- Предпросмотр работает и для неполной формы. Пока есть ошибки, доступен только файл «Скачать черновик» с пометкой BOZZA на каждой странице; неизвестные суммы остаются прочерками. После исправления полей доступен готовый PDF. Ошибка предпросмотра не блокирует скачивание уже сформированного файла.

Локальный запуск: `python -m http.server 8000` из корня проекта.
Проверки расчётов и валидации: `node --test tests/account-core.test.cjs`.
